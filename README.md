🚀 ABHH-Abhhash Host

Abhhash Host is a modern, visually appealing website hosting platform UI demo built using HTML, CSS, and JavaScript.

It features a dark theme, animated RGB gradients, glowing effects, and a clean, responsive layout.

✨ Features

- 🎨 Modern dark UI with animated RGB backgrounds
- 🌈 Glowing visual effects and floating RGB orbs
- 📱 Responsive layout for different screen sizes
- ⚡ Hosting platform landing page design
- 📂 File selection UI for demonstration
- 🖱️ Interactive buttons with JavaScript alert messages
- 💻 Built with pure HTML, CSS, and JavaScript

⚠️ Important Notice

This project is currently a frontend-only UI demo.

It is designed for visual preview and demonstration purposes only.

- ❌ No real file uploading
- ❌ No actual website hosting or deployment
- ❌ No backend or database
- ❌ No real shareable URLs are generated

The upload button only displays a demo message. No files are uploaded to a server.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

▶️ How to Run

1. Download or clone this repository.
2. Open the "index.html" file in your browser.
3. Explore the Abhhash Host UI demo.

No installation or additional dependencies are required.

🎯 Project Purpose

This project demonstrates the frontend design of a modern website hosting platform. It can serve as a starting point for future development with real uploading, hosting, and deployment functionality.
